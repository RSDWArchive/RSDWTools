# Quest Editor

Tool page at `/tools/quest-editor/` that lists quests from the generated
QuestData catalog and marks overall quest completion in a loaded player JSON.

## Data Source
- Quest metadata comes from
  `E:\Github\RSDWArchive\website\tools\QuestData\QuestData.json`.
- The UI catalog is generated by:

```
python tools/build_quest_catalog.py
```

Output:
- `website/tools/quest-editor/data/quests.json`

## Player Save Mapping
- Player JSON stores quest rows under `QuestProgress.Quests`.
- Each row is matched by `QuestId`, which corresponds to the quest
  `persistence_id` in the generated catalog.
- A quest is complete when any matching row has `QuestState` set to `2`.

## Save Behavior
- V1 is completion-only. Existing completed quests are locked in the UI.
- Newly checked quests are saved by setting matching rows to `QuestState: 2`.
- If a checked quest has no existing row, the editor appends a minimal complete
  row with `QuestObjective: "None"`, empty `QuestInts`, and empty `QuestBools`.
- The editor preserves `QuestLocations`, `QuestTracked`, metadata, GUID, and all
  non-quest save sections.
